# Bonnie's 75th Birthday Quest

This is a simple, phone-friendly prototype. Open `index.html` in a browser.

The current stops are placeholders:
1. Camelot
2. Goodwill
3. FINS
4. Final dessert surprise

The clues and destinations can be edited directly in the `stops` section of index.html.

Important: this prototype is intentionally simple and does not yet have a true remote "Quest Master" control panel. The "We Did It!" button advances the quest on the same device. A next version can add a shared/private unlock system so Stacey can release each clue remotely.
